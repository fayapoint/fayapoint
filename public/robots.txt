# Block all private/dynamic areas
#
# Revisado em 29/07/2026. Duas correcoes, e a segunda inverte uma decisao.
#
# 1) Nenhum destes padroes casava com o prefixo de locale. A URL real do painel
#    e /pt-BR/admin/, nao /admin/ — o bloqueio nunca valeu para ela. Por isso as
#    variantes com prefixo entram explicitamente.
#
# 2) As paginas de conta (login, registro, portal, checkout...) SAIRAM daqui de
#    proposito. Elas ja estavam sendo rastreadas apesar do Disallow, e bloquear
#    e o oposto do que se quer: URL bloqueada no robots.txt pode continuar
#    indexada so pela URL, porque o Google nunca chega a LER a tag que manda
#    remove-la. Agora cada uma serve <meta name="robots" content="noindex"> e
#    precisa ser rastreavel para que essa tag seja vista e obedecida.

Disallow: /admin/
Disallow: /pt-BR/admin/
Disallow: /en/admin/
